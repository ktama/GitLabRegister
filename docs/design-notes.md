## Phase 2: 承認を得た判断 (2026-10-03)

| ADR | 決定 | 経緯 |
|---|---|---|
| ADR-01 | Tauri 2 + Rust、WebView2 は OS 同梱前提 (skip) | 当初は WPF を推奨した。依頼者から Tauri の比較を求められ、WebView2 の配布条件を公式ドキュメントで確認。Windows 11 前提にすれば起動不可リスクが消えることが判明し、対象 OS を Windows 11 専用に狭める要件変更 (要件書 版 0.6) と合わせて Tauri を採用 |
| ADR-03 | すべてテキストファイル (構造化テキスト + 1 行 1 件の追記形式) | FR-18 の受け入れ基準を変換層なしで満たせる |
| ADR-05 | Issue 作成後に別操作でイテレーションを設定 | FR-06 が失敗の検知と表示を要求するため、説明文への命令埋め込み案では満たせない |

### WPF から Tauri へ推奨を変えた理由

当初 WPF を推した 3 つの理由のうち、2 つが Windows 11 前提で成立しなくなった。
外部ランタイム依存は WebView2 が OS 構成要素であることで消え、NFR-05 に対する追加の面 (WebView2 のユーザーデータフォルダ) は一度の設定で閉じられる範囲だと確認できた。
残る差は FR-08 のグリッド工数のみで、言語の習熟度を上回る決め手にならないと判断した。

### 公式ドキュメントで確認した事実

| 確認事項 | 結果 |
|---|---|
| Windows 11 の WebView2 | OS の構成要素として常に同梱 |
| Windows 10 の WebView2 | 2023 年 1 月以降に配布。大多数に導入済みだが未導入端末が一部残る |
| Tauri の WebView2 同梱方式 | skip (0 MB・前提) / downloadBootstrapper (0 MB・要通信) / embedBootstrapper (約 1.8 MB・要通信) / offlineInstaller (約 127 MB) / fixedVersion (約 180 MB) |
| ユーザーデータフォルダの固定 | 環境変数による指定が実装側の値を上書きする。アプリが起動の最初に設定すれば固定できる |
